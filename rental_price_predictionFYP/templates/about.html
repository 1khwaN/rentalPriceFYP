📘 About the Rental Price Prediction System

Learn how RPPSHomes uses AI and data engineering to deliver accurate rental estimations.

RPPSHomes is an AI-powered rental price estimation platform built for properties in Kuala Lumpur and Selangor. The system integrates machine learning, geolocation, data engineering, and recommendation intelligence to deliver accurate rental predictions.

Key capabilities of the system include:
  • ⚙️ Hybrid Machine Learning Model — combines Random Forest and XGBoost for improved accuracy.
  • 📍 Geolocation-Based Price Recommendations — compares rental prices within the same area.
  • 🗺️ Interactive Mapping — displays predicted location and nearby recommended listings.
  • 🏢 Property Feature Engineering — size, age, room ratios, price per sqft, furnishing, parking.
  • 🎯 Location-Aware Predictions — automatically adapts based on city & region behavior.
  • ⭐ Top Property Recommendations — sorts listings similar to the predicted price range.
  • 📊 Analytics Dashboard Integration (PowerBI) — provides market insights and visual dashboards.
  • 🧹 Robust Data Cleaning Engine — removes outliers, wrong values, and inconsistent formats.
These features work together to help users make informed decisions when evaluating rental prices for homes and apartments across Klang Valley.

🔮 Prediction Engine

Uses advanced regression models to estimate monthly rental prices based on property size, location, and features.

📍 Geolocation Mapping

Displays predicted location and recommended property prices using Leaflet maps.

⭐ Recommendation System

Suggests nearby listings that match the expected rental range (±10% of prediction).

📊 Analytics Dashboard (PowerBI)

Provides interactive analytics for rental trends, demand insights, and price distribution.
